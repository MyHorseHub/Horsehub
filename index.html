🧭 Lokale Schreibdiagnose 1.21

Zeichnet lokale Schreibvorgänge für synchronisierte Daten auf. Besonders wichtig: Wenn ein Datensatz z. B. von 4 auf 3 Einträge fällt, werden Quelle und Aufrufpfad protokolliert. Es werden keine Daten verändert.

🔎 Sync-Diagnose – Legacy-Diagnose + Sync V2

Prüft lokalen und Cloud-Stand. Zusätzlich gibt es einen sicheren Roundtrip-Test über eine eigene Diagnose-Tabelle. Dabei werden keine Pferde, Fütterungen oder Aufgaben verändert.

↔️ Bidirektionaler Roundtrip-Test
Start auf diesem Gerät → Cloud → zweites Gerät → Cloud → zurück auf dieses Gerät. Der Test verwendet nur einen isolierten Datensatz in horsehub_sync_diagnostics.
📤 Legacy Upload-Diagnose 1.23.0
Prüft den Upload des ausgewählten Pferdes und protokolliert lokalen Stand, Cloud-Stand vor dem Upload, Payload-Zähler, Supabase-Antwort und anschließenden Cloud-Readback.
🧪 Legacy-Tiefendiagnose für Pferde-Sync
Prüft zusätzlich den echten lokalen Datensatz, den Cloud-Datensatz, den gespeicherten Cloud-Basisstand, einzelne Fütterungseinträge, den aktuellen Sync-Entscheidungsweg und den lokalen Sync-Verlauf. Es werden keine Pferdedaten verändert.
